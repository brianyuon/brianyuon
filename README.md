🎮 The Golden Era of Video Games (1995–2015) Analyzed 7,744 titles to see whether critical acclaim actually drove sales. Found that critically acclaimed games sold ~3x more than well-reviewed ones — but Nintendo still out-sold everyone despite not having the top scores. 🔗 Tableau Dashboard
